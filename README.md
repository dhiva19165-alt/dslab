# Data Structures Lab Programs (C)

Clean, compilable C implementations of the Data Structures lab experiments.

## Currently Available Programs

| File | Topic |
|------|-------|
| `03A_Array_Stack.c` | Array Implementation of Stack |
| `03B_Array_Queue.c` | Array Implementation of Queue |
| `04A_LinkedList_Stack.c` | Linked List Implementation of Stack |
| `04B_LinkedList_Queue.c` | Linked List Implementation of Queue |
| `10A_Linear_Search.c` | Linear Search |
| `10B_Binary_Search.c` | Binary Search |
| `10C_Insertion_Sort.c` | Insertion Sort |

## How to compile & run

```bash
gcc filename.c -o program
./program
```

Most programs are menu-driven interactive programs.
